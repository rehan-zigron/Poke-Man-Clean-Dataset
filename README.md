# Pokémon Dataset 🐱‍👤

A clean Pokémon dataset created using Python by fetching data from the PokeAPI.

## About

This dataset contains information about 10 Pokémon including their id, name, height, weight, base experience, types, and abilities. The data was fetched using the `requests` library and cleaned with `pandas` into a simple tabular format.

## Files

- `clean-pokemon2.csv` — Main dataset
- `pokemon.ipynb` — Jupyter notebook used to create the dataset

## Source

Data from [PokeAPI](https://pokeapi.co/).
